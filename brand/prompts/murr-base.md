# Murr base v1 prompt

`brand/art/laika-base.png`는 거친 1950년대 기술 스크린프린트 질감과 기록화 구도만 참조했다. 라이카의 개 정체성, 하네스, 우주선, 원형 창과 자세는 복제하지 않았다.

마른 성묘 태비 무르가 지구의 낡은 무선 수신실 책상에 앉아 한 발을 한 버튼 조작기에 올린다. 한쪽 귀에는 작은 흠집, 옅은 주둥이, 짙은 이마 줄무늬와 호박색 눈이 있다. 주변에는 오래된 수신기, 천 피복 케이블, 책상 조명, 작은 기록장과 비 내리는 창이 있다.

검정과 더티 화이트의 거친 망점·식각 질감에 이끼색만 제한적으로 쓴다. 자연스러운 네 발 고양이 골격을 유지한다. 의인화된 손, 옷, 목걸이, 헬멧, 개의 특징, 로켓, 우주선, 원형 창, 행성, 현대 UI, 문자, 로고, 서명과 워터마크는 제외한다.
