# Reference adaptation

## 기준작 선택

- 선택된 장르의 실제 출시 게임 하나를 주 기준작으로 고른다.
- 규칙과 한 판 흐름을 확인할 수 있는 공식 설명, 매뉴얼, 스토어 정보 또는
  실제 플레이 자료를 조사한다.
- 모호한 분위기 참고가 아니라 플레이 구조를 가져올 수 있는 게임을 고른다.
- 이전 Laika 게임은 기준작으로 사용하지 않는다.

## 유지와 변경

GDD 첫 부분에 다음을 짧고 구체적으로 쓴다.

1. `기준 게임`: 제목과 어떤 판본을 봤는가
2. `유지`: 입력→판정→보상→다음 선택으로 이어지는 핵심 루프
3. `변경`: 정확히 2~3개 축
4. `한 판`: 인트로부터 게임 결과까지 플레이어 행동을 순서대로
5. `체험판 경계`: 전체 게임에서 이번 빌드가 제공하는 구간

“영감을 받았다”, “현대적으로 재해석한다” 같은 문장으로 대신하지 않는다.
고정된 레트로 아트 방향은 변경 축에 세지 않는다. 핵심 루프와 기능 범위를
잠근 뒤 별도 아트 패스로 적용한다.

## 기능 범위표

기준작의 주요 시스템을 아래 셋 중 하나로 분류한다.

- `FULL`: 체험판에서 출시 품질로 구현
- `ADAPTED`: 세로 모바일이나 어레인지에 맞춰 바꿔 구현
- `OUT`: 체험판 범위 밖이며 UI와 카피에서도 약속하지 않음

`FULL`과 `ADAPTED`는 임시 UI, 가짜 선택과 “추후 제공” 상태로 둘 수 없다.
`OUT`을 잠긴 메뉴나 비어 있는 화면으로 노출하지 않는다.

## 필수 상태 흐름

1. `INTRO`: 세계와 이번 체험의 상황을 보여 준다.
2. `TITLE`: 제목, 시작 입력과 필요한 설정을 제공한다.
3. `GAME`: 기준작의 핵심 루프, 변주와 절정을 플레이한다.
4. `RESULT`: 승패 또는 체험판 완료 결과와 다시 시작 경로를 제공한다.

상태 이름은 화면에 그대로 쓸 필요가 없지만 런타임과 테스트에서는 구분 가능해야
한다. 시작부터 결과까지 네 상태를 건너뛰지 않는다.

## 체험판 완성

체험판은 콘텐츠의 일부지만 경험은 닫혀 있어야 한다.

- 시작 방법을 화면에서 알 수 있다.
- 핵심 루프를 여러 번 사용하며 차이를 배우게 한다.
- 난도·상황·상대 또는 공간의 변주가 있다.
- 이번 범위의 절정과 결과가 있다.
- 다시 플레이하거나 종료할 수 있다.
- 아트, 사운드, 피드백과 양언어가 임시 상태가 아니다.
