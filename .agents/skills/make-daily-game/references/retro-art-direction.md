# Retro art direction

게임 규칙과 체험판 범위를 잠근 뒤 적용한다. 아트 스타일을 이유로 기준 게임의
핵심 루프를 단순화하거나 다른 장르로 바꾸지 않는다.

## 2D

- 16비트 SNES 계열 도트 아트로 만든다.
- 캐릭터, 배경, 이펙트와 플레이 UI를 픽셀 그리드에 맞춘다.
- 제한 팔레트와 명확한 실루엣을 사용한다.
- 낮은 원본 해상도에서 제작하고 nearest-neighbor로 확대한다.
- 고해상도 회화, 매끈한 벡터 아이콘과 서브픽셀 선을 주 화면에 섞지 않는다.

ART.md에 원본 캔버스 크기, 스프라이트 크기, 팔레트와 확대 방식을 기록한다.

## 3D

- PSX 계열의 레트로 로우폴리 스타일로 만든다.
- 낮은 폴리곤 수의 분명한 실루엣과 저해상도 픽셀 텍스처를 사용한다.
- 낮은 내부 해상도로 렌더하고 nearest-neighbor로 확대한다.
- 현대적 PBR, 고밀도 메시, 포토리얼 조명과 매끈한 고해상도 재질을 쓰지 않는다.
- 버텍스 흔들림, affine texture와 dithering은 작품에 맞을 때만 사용한다.

ART.md에 대표 모델의 폴리곤 범위, 텍스처 크기와 내부 렌더 해상도를 기록한다.

## 혼합형

2D 레이어는 2D 기준을, 3D 레이어는 3D 기준을 각각 따른다. 타이틀과 결과만
레트로이고 실제 게임은 다른 스타일인 경우 통과하지 않는다.
