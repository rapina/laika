# Brand-blind creator workflow

## 제작 목표

세로형 모바일 디바이스에서 플레이할 수 있는 풀 프로덕션급 웹 게임을 만든다.
프로토타입, 기술 데모, 게임잼 출품작처럼 축약하지 않는다. 출시할 완성작이라고
판단할 때까지 필요한 시간과 자원을 사용한다.

관제가 전달한 주 장르 하나를 플레이의 골격으로 사용한다. 장르명이나 외형만
빌리지 말고, 함께 전달된 완성 약속 4~6개가 실제 한 판에서 작동하게 만든다.
그 위에 세계, 소재, 규칙, 보조 장르와 기술을 자유롭게 결합한다.

그 밖의 결정은 제작자의 것이다.

- 장르, 규칙, 길이, 종료·점수·실패 유무, 난이도와 언어
- 탭, 드래그, 멀티터치와 다른 입력 조합
- DOM, Canvas, WebGL, WebGPU, 셰이더, 물리, 영상, 생성 이미지와 외부 자산
- 기존 게임의 모방, 변형과 재창작
- HUD, 튜토리얼, 재화, 업그레이드, 파티클과 장식 효과
- 결정론, 비결정론과 자동 완주 가능성
- 게임별 테스트의 범위, 방식과 도구
- 제작 자원의 규모

SVG와 Canvas/Pixi의 기본 도형은 보조 매체로 쓸 수 있다. 그러나 게임 아트
전체를 SVG, 아이콘, 원·선·사각형과 단색 도형만으로 끝내지 않는다. 실제 플레이
장면의 정체성을 만드는 주 매체 하나 이상은 래스터 페인팅·생성 이미지·촬영
이미지·텍스처가 입혀진 3D·영상·셰이더 재질·직접 그린 비트맵 등 비SVG 매체로
만든다. 파비콘, 검증 스크린샷과 잠금 뒤 공개용 라이카 일러스트는 이 조건을
대신하지 않는다.

후보 수, 동적 매체 후보, 하나의 상호작용·재료·대표 색, 깊이 축과 감산을
의무화하지 않는다. 제작자는 원하는 아이디어를 바로 선택할 수 있고 사용자에게
창작 결정을 묻지 않는다.

## 기록

코드를 시작하기 전에 최소한 다음만 중립 문서에 적는다.

- `GDD.md`: 무엇을 만들며 세로 모바일에서 어떻게 조작하는가
- `DAY.md`: 실제 제작 과정, 실행한 확인과 남은 문제
- `ART.md`: 사용한 자산·도구·참고 자료와 확인한 범위의 출처
- `game.manifest.json`: 식별자, 제목, 지원 언어, 조작, 세로 화면과 릴리스 엔트리

목표 화면, 키 이미지, 시뮬레이션, 점수표와 게임 오버 화면은 게임에 필요할 때만
만든다. `WHY.md`, 라이카 일러스트, 공개 카피와 크레딧은 제작 잠금 전에는 만들지
않는다.

ART.md에는 비SVG 주 매체의 원본, 제작 도구, 후가공, 실제 플레이 사용 위치를
적는다. 파일 자산이라면 원본과 게임용 파생본을 게임 저장소에 둔다.

GDD에는 `주 장르`, `장르의 완성 약속`, `콘텐츠와 진행의 끝`을 명시한다.
완성 약속은 “재미있다” 같은 평가가 아니라 실제 빌드에서 확인할 수 있는
플레이 구조다. 예를 들어 슈팅이면 적 패턴, 무기 차이, 피격과 회복, 보스 또는
동등한 절정처럼 그 작품이 완성작으로 읽히는 구체적 요소를 적는다.

## 구현

- 390×844를 대표 화면으로 삼고 360×800과 430×932에서도 핵심 플레이 영역이
  잘리거나 가려지지 않게 한다.
- 화면에 보이는 주 입력을 실제 터치·포인터로 수행할 수 있게 한다.
- 게임이 제공하는 기능만 구현한다. 종료, 결과, 재시작, 키보드, 양언어, 음향,
  저장과 일시정지를 검증 편의를 위해 추가하지 않는다.
- 기술과 자원 규모를 제한하지 않는다. 큰 자산이나 초기 로딩이 게임의 선택이면
  기록하고 그대로 사용할 수 있다.
- 외부 작품과 자산을 사용하거나 모방했다면 숨기지 말고 `ART.md`에 적는다.
- GDD에 적은 규칙과 로직 가운데 결함이 생길 수 있는 부분을 제작자가 직접
  고르고, 그 게임에 맞는 테스트를 작성한다.

## 제작 완료

첫 구현은 제작 완료가 아니다. 제작 맥락을 모르는 플레이어가 실제 빌드만
플레이한 관찰을 받고 게임을 다시 만든다.

제작자가 원하는 완성작이 GDD대로 구현됐고, 내부 플레이 관찰을 반영한 재제작과
게임별 테스트가 끝나 출시할 프로덕션 빌드를 만들 수 있으면 제작 완료다.
테스트는 결정론이나 자동 완주를 증명할 필요가 없다.

짧은 한 판도 허용하지만 콘텐츠가 한 규칙의 시연으로 끝나서는 안 된다. 선택한
장르의 학습, 변주, 압박과 절정이 플레이 안에 있어야 한다.
