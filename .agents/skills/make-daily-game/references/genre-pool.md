# Genre pool

매 게임에서 주 장르 하나를 고른다. 세계관이나 시각 소재가 아니라 플레이
구조를 고르는 목록이다. 보조 장르와 다른 규칙의 결합은 자유다.

- 생존 아레나
- 플랫폼 액션
- 러너

## 선택 방법

1. 최근 10편의 구조 지문을 비교한다.
2. 최근 5편에서 쓰지 않은 주 장르를 우선한다.
3. 후보 장르를 세계·소재와 결합한 뒤 실제 플레이 구조를 다시 비교한다.
4. 최근작과 `주 입력 / 공간 구조 / 역할 / 실패 / 진행 / 표현` 중 세 항목
   이상이 겹치면 다른 후보를 고른다.
5. 장르의 대표작을 참고하거나 그대로 변형해도 된다. 새로워 보이기 위해 장르의
   핵심을 지우지 않는다.

## 완성 판단

장르를 고른 뒤 그 게임에 필요한 완성 약속 4~6개를 제작자가 작성한다. 다음을
포함하되 고정 체크리스트로 사용하지 않는다.

- 익힐 수 있는 핵심 루프
- 루프를 바꾸는 적, 코스, 상황 또는 상대
- 의미가 다른 선택이나 도구
- 실패·회복 또는 위험의 피드백
- 학습 뒤에 오는 변주와 절정
- 한 작품으로 닫히는 결과 또는 지속 구조

메뉴 수, 스테이지 수, 플레이 시간으로 완성을 대신 증명하지 않는다. 반대로
핵심 규칙 하나와 점수판만 있는 빌드는 프로토타입으로 본다.
