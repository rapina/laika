# Creator verification

프로젝트의 `package.json`과 실제 스크립트를 먼저 읽는다. 없는 명령을 통과한 것처럼 기록하지 않는다.

최소 검증:

```bash
npm test
npx tsc -b
npm run build:web
```

게임별 smoke와 viewport 검증이 있으면 함께 실행한다.

```bash
npm run smoke
node scripts/viewport-smoke.mjs
```

다음 동작을 실제 브라우저나 자동 플레이로 확인한다.

- 첫 화면에서 규칙 이해
- 성공과 실패 판정
- 한 판 전체 완주와 90초 이내 종료
- 진행 중 시스템 반응이나 긴장 변화
- 일시정지 중 시뮬레이션 정지와 복귀 뒤 시간 안정성
- 음소거와 다시 켜기, 첫 입력 전 무음
- 재시작 뒤 초기 상태 복원
- 한국어와 영어의 기능·정보 일치
- 플레이 중 언어 변경 시 상태 유지
- 360×800, 390×844, 430×932 화면
- 대표 장면과 선택한 시각 매체의 식별성
- 콘솔 오류, 페이지 오류, 실패 요청 0건

자동 플레이는 개발 빌드의 결정론적 테스트 훅을 사용할 수 있다. 문구나 화면 좌표만으로 완료 여부를 추측하지 않는다.

다음 중 하나라도 남으면 제작 잠금을 만들지 않는다.

- 임시 자산이나 템플릿 문구
- 한국어·영어 누락
- 출처가 없는 게임 자산
- 결정론 테스트 실패
- 화면 넘침이나 브라우저 오류
- 콘셉트 잠금과 다른 규칙, 세계 또는 대표 장면
