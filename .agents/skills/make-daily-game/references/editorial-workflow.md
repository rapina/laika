# Laika maker-narrative workflow

이 문서는 제작 잠금 뒤에만 읽는다.

## 작품 노트

완성된 게임을 직접 플레이하고 다음만 설명한다.

- 처음 감지한 재료의 감각이나 움직임
- 끝까지 남은 조작과 선택
- 감산 뒤 더 또렷해진 대표 장면
- 실제 검증에서 확인한 결과

라이카가 게임을 직접 만든 제작자로 설명한다. 주제와 선택의 이유는 잠긴 `DAY.md`, `GDD.md`, `ART.md`에서 가져오고 기록에 없는 동기나 결정을 만들지 않는다. 기능 목록과 판정 수치는 `GDD.md`와 테스트에 남긴다.

한국어와 영어가 같은 내용을 전달하게 한다. 한국어 `멍!`, 영어 `Woof!`는 각각 한 호흡만 사용한다.

## 제작자 일러스트

1. 잠긴 마지막 장면과 대표 행동을 그대로 읽는다.
2. `brand/art/laika-base.png`를 실제 이미지 참조로 전달한다.
3. 얼굴 무늬, 귀, 흰 가슴과 앞발, 크림색 X자 하네스, 주황 연결구를 유지한다.
4. 잠긴 게임의 도구 하나와 행동 하나만 가져온다.
5. 문자, 로고, 서명, 가짜 역사 표식, 여분의 발, 사람 손을 거부한다.
6. 생성 원본을 `art/source/laika-<slug>.png`에 보관한다.
7. 카드용 640px, 상세용 1280px JPEG를 만든다. 원본 PNG는 릴리스하지 않는다.
8. 프롬프트, 해시, 얼굴·골격·문자·모바일 크롭 검수를 기록한다.

캡슐, 원형 창, 지구와 라이카 팔레트는 이 일러스트에만 쓴다. 게임 UI, 게임 아트, 게임 사운드에 추가하지 않는다.

## 공개 메타데이터

- `.studio.json`에 서사 준비 상태, 스튜디오, 제작자와 베이스 일러스트 정보를 유지한다.
- `game.manifest.json`의 잠긴 제목, 소개, 조작, 세션과 게임 미디어는 유지한다.
- manifest에는 `credits`, `whyCreated`, `media.makerIllustration`만 추가한다.
- manifest 크레딧은 `Sputnik Workshop` / `Laika` / `autonomous game-making agent`로 기록한다.
- 공개 크레딧은 `A game by Laika at Sputnik Workshop`을 기준으로 한다.
- 카탈로그 제작 노트는 기능보다 주제와 핵심 선택을 앞에 둔다.

`.creator-lock.json`은 읽기 전용이다. 라이카 제작 서사 뒤 제작 잠금 검증을 실행한다. 잠긴 파일이 바뀌면 서사 작업을 되돌리고 공개를 중단한다.
