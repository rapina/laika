# Production Bar

sequence 22부터 게임의 창작 제약은 하나다.

> 세로형 모바일 디바이스에서 터치로 플레이되는 웹 게임이어야 한다.

## 자유

- 장르, 규칙, 세션 길이, 종료·점수·실패 유무와 난이도는 자유다.
- DOM, Canvas, WebGL, WebGPU, 셰이더, 물리, 영상, 생성 이미지와 외부 자산을 자유롭게 사용한다.
- 기존 게임을 모방·변형·재창작하거나 최근 작품과 비슷하게 만들어도 된다.
- 언어, HUD, 튜토리얼, 효과, 자원 규모와 테스트 가능성을 의무화하지 않는다.
- 결정론, 자동 완주, 깊이, 목표 화면, 감산은 공개 조건이 아니다.

## 치명 결함

체르파는 다음 경우에만 공개를 막는다.

- 빌드 또는 필수 자산이 뜨지 않아 플레이 화면을 사용할 수 없다.
- 세로 모바일 화면에서 핵심 플레이 영역이 잘리거나 가려진다.
- 실제 터치 입력을 넣을 수 없거나 첫 상호작용 뒤 반복 충돌한다.
- 일시정지·복귀 뒤 입력과 화면이 영구적으로 멈춘다.
- 검토한 소스와 공개할 빌드가 다르다.
- 운영자 승인이 필요한 결제·개인정보 수집·새 유료 리소스가 승인 없이 들어갔다.

난해함, 미완주, 낮은 완성도, 불친절한 안내, 기존 게임과의 유사성,
자동 테스트 불가, 종료·재시작 부재는 관찰 사항이지 차단 사유가 아니다.

## 출고 확인

- 360×800, 390×844, 430×932 중 대표 세로 화면에서 핵심 영역을 확인한다.
- 포털에서 빌드와 필수 자산이 로드되고 콘솔·페이지 오류가 없는지 확인한다.
- 화면에 보이는 주 입력을 실제 포인터로 한 번 이상 수행하고 반응을 확인한다.
- 게임이 결과·재시작·언어 전환을 제공할 때만 해당 기능을 검사한다.
- 릴리스 파일의 경로, 해시와 불변 SHA를 기록한다.

sequence 21까지의 게임은 당시 채택된 품질 기준과 공개 기록을 그대로 보존한다.
