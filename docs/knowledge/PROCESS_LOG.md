# 공정 로그 (PROCESS_LOG)

게임이 아니라 **게임을 만드는 방법**이 바뀌어 온 내부 기록이다. 공정(워크플로, 게이트, 페르소나, 공개 형식)을 바꾸는 세션은 작업 전에 이 파일을 읽고, 바꾼 뒤에 다음 세 곳을 함께 갱신한다.

1. 이 파일에 항목 추가 (날짜, 계기, 변경, 강제 위치)
2. 공개 페이지 데이터 `arcade/public/catalog/process.json` 갱신. `/history`에 렌더된다. ko·en 필수, 긴 줄표 금지, `arcade/scripts/validate.mjs`가 스키마를 검사한다.
3. 구조적 결정이면 `docs/architecture/` ADR 작성

"강제 위치"는 그 규칙을 기계적으로 강제하는 스크립트나 게이트다. 문서에만 있는 규칙은 지켜지지 않았던 것이 이 로그의 반복 교훈이다.

- **증거 해시가 추적하지 않는 파일을 포함했다.** `sourceHash`가 `src/`·`public/`를 디스크로 훑어 Finder가 만든 `.DS_Store`까지 해시에 넣고 있었다. 그 파일 하나를 지우자 **추적 소스가 한 바이트도 안 바뀌었는데 통과한 설계 검토가 무효가 되고 게시가 막혔다.** 지운 원본 바이트는 복구할 수 없어 되돌릴 수도 없었다. 조치: 게임·템플릿·관제 세 곳 모두 git 추적 파일만 해시하도록 고치고(저장소가 아니면 예전 동작으로 후퇴해 픽스처 시험 유지), 검토를 다시 돌려 새 해시에 묶었다. 재검토자가 review-3 트리를 꺼내 같은 해시가 나오는 것까지 확인했다.
- **뷰포트 증거가 조용히 낡았다.** `viewport-smoke.mjs`가 측정 JSON이 바뀔 때만 캡처를 다시 썼다. 배경 애니메이션으로 저장소가 더러워지는 것을 막으려던 것인데, 수치가 그대로인 순수 렌더 변경에서는 커밋된 이미지가 낡은 채 남았다. 보고서에 소스 해시를 넣어 해결하고, `sourceHash`를 `launchpad/scripts/source-hash.mjs` 한 곳으로 모았다(smoke와 viewport가 각자 계산하고 있었다).
- **관제가 게임 커밋을 템플릿 저장소에 push했다.** `new-day.mjs`가 launchpad를 clone하면서 `main`이 `launchpad/main`을 추적한 채 남는데, 게임에는 아직 자기 origin이 없다. 인수 없는 `git push` 한 번에 게임 커밋 4개가 템플릿 main으로 넘어갔고 force-push로 되돌렸다. 조치: scaffold가 추적을 끊어, origin이 생기기 전의 push는 대상을 못 찾고 그냥 실패한다.
- **공개 뒤에야 잡힌 것 (게이트가 놓친 것).** 영어 첫 판 안내 세 줄이 고정 간격에 놓여, 영어 1번 문장이 네 줄로 접히며 2번 문장을 덮었다. 하필 그 줄이 이 게임의 핵심(모래가 늦게 온다)을 가르치는 문장이다. 한국어는 우연히 들어맞아 멀쩡했다. 뷰포트 게이트는 로케일 두 개를 돌지만 **결과 화면의 잘림**만 보고 안내 패널 안의 줄 겹침은 보지 않는다. 독립 검토 네 번이 나란히 놓쳤고, 공개 후 관측자 두 명이 각각 잡았다. 조치: 세 줄을 실제 높이로 흘려 놓고 패널을 그 높이에 맞춰 어떤 언어도 겹치지 않게 했다. 안내 문구의 긴 줄표도 함께 제거했다(공개 문구 금지 규칙인데 화면 문자열에는 검사가 없었다).
- 일반화한 결함 유형: **한 언어가 들어맞았다는 것은 레이아웃이 옳다는 뜻이 아니다.** 번역은 글자가 아니라 배치다. 가장 길게 접히는 로케일을 가장 좁은 상자에 넣어 보고, 가장 중요한 문장부터 확인한다. 남은 부채로 남긴다 — 안내 패널 줄 겹침을 재는 자동 검사는 아직 없다.
- 남은 것: 지구 평가가 **실기 플레이에 실패했다.** 평가자의 도구가 `sandbox="allow-scripts"` iframe 안으로 포인터 이벤트를 넣지 못해 44종 중 2종까지만 보고 끝났다. 노린 감각이 실제로 전달되는지는 아직 아무도 답하지 못했다. `earthReview`는 미기록으로 두었고(최신 한 편까지 허용), 다음 사이클이 iframe 안으로 실제 입력을 넣을 수 있는 평가 경로로 먼저 채워야 한다.
- 강제 위치: `launchpad/scripts/source-hash.mjs`, `launchpad/scripts/arcadeEntry.ts`(unsafe-eval), `launchpad/scripts/build-release.mjs`·`verify-release.mjs`(일러스트 선택), `launchpad/scripts/viewport-smoke.mjs`(보고서 소스 해시), `scripts/prepare-editorial.mjs`(추적 파일만 해시), `scripts/new-day.mjs`(업스트림 해제), `docs/knowledge/CRAFT.md`(계단 응답·`data:` 텍스처). 안내 패널 겹침 검사는 **강제 위치 없음 — 부채**.
