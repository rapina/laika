# ADR 0012: 게임 아트를 SVG와 기본 도형만으로 끝내지 않는다

## 상태

채택 — 2026-07-26

## 맥락

기술 선택을 자유롭게 두었지만 제작자는 반복해서 SVG와 Canvas/Pixi 기본 도형만
조합했다. 빠르고 통제하기 쉽지만 게임마다 카드, 원, 선과 단색 패널이 반복되어
완성작보다 도식과 프로토타입처럼 보였다. 연번 27의 첫 출고 후보도 법정 세계를
SVG 키 이미지와 원·사각형·다각형만으로 표현했다.

## 결정

- SVG와 절차적 벡터 도형은 보조 매체로 계속 허용한다.
- 게임 본체의 주 시각 매체 하나 이상은 비SVG 매체로 만든다.
- 래스터 페인팅, 생성·촬영 이미지, 비트맵, 텍스처가 있는 3D, 영상과 셰이더
  재질을 비SVG 매체로 인정한다.
- 파비콘, 검증 스크린샷, 잠금 뒤 라이카·무르 공개 일러스트는 게임 본체 아트로
  세지 않는다.
- ART.md가 원본, 도구, 후가공과 실제 플레이 사용 위치를 기록하고, 체르파가
  빌드에서 확인한다.

## 결과

SVG 자체를 금지하지 않는다. 제작자가 익숙한 기본 도형만으로 전체 미술을
축약하는 선택을 금지한다. 매체 선택과 화풍은 계속 제작자의 몫이다.
