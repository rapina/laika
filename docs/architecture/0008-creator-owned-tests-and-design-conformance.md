# ADR 0008: 제작자 소유 테스트와 디자인 일치 검사

- 상태: 채택
- 날짜: 2026-07-26
- 적용: sequence 23부터
- 대체 범위: ADR 0007의 고정 fatal 검사와 체르파 역할

## 결정

라이카가 게임 디자인, 구현과 로직 테스트를 모두 소유한다.

- 장르, 규칙, 기술, 결정론 여부, 종료 구조와 테스트 방식은 라이카가 정한다.
- 자동 완주, 결정론, 고정된 테스트 항목과 테스트 개수는 요구하지 않는다.
- 라이카는 디자인 문서에 자신이 만들 게임을 적고, 그 로직에 결함이 없는지
  판단할 테스트를 직접 작성해 실행한다.
- 비결정적 게임은 결과값 고정 대신 라이카가 중요하다고 정한 불변 조건을
  테스트할 수 있다.

체르파는 게임 디자인을 평가하거나 테스트 항목을 대신 만들지 않는다. 다음만
확인한다.

1. 디자인 문서에 적힌 약속이 실제 빌드에 구현됐는가.
2. 라이카가 작성한 게임별 테스트가 실행되어 통과했는가.
3. 그 빌드를 공개할 수 있는 상태인가.

문서와 빌드가 일치하고 제작자 테스트가 통과하며 배포 가능한 빌드가 있으면
체르파는 통과시킨다. 재미, 난이도, 설명 방식, 깊이, 기존 게임과의 유사성,
테스트 전략의 취향은 판정하지 않는다.

무르는 배포된 게임만 플레이한다. 완주 여부와 관계없이 실제 경험, 잘 닿은 점과
걸린 점을 기록하며 공개 전 판정에 참여하지 않는다.

## 검증 경계

고정 자동 검사는 게임 품질을 주장하지 않는다. 다음 배포 상태만 확인한다.

- 빌드와 엔트리가 열린다.
- 필수 자산 요청이 성공한다.
- 세로 모바일 화면에서 실행된다.
- 콘솔·페이지 오류가 없다.
- 검토한 sourceHash와 공개할 릴리스가 같다.

터치 뒤 화면 변화, 자동 완주와 특정 게임 상태는 공통 스모크의 합격 조건이
아니다. 그런 동작이 디자인 문서의 약속이면 라이카의 게임별 테스트와 체르파의
문서 일치 검사에서 다룬다.

## 이유

고정된 게임플레이 스모크는 검증 가능한 게임을 만드는 대신 체크리스트에 반응하는
게임을 만들게 했다. sequence 22 「유리잠수」에서는 포인터 뒤 화면이 바뀐다는
사실만으로 통과했지만, 그 검사는 얼음과 물고기의 관계를 전혀 확인하지 않았다.

게임마다 로직이 다르므로 테스트 내용도 제작자가 정해야 한다. 체르파는 새 기준을
추가하지 않고 제작자가 문서로 약속한 것과 실제 결과가 같은지만 독립적으로 본다.
