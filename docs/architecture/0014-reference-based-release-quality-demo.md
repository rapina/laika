# ADR 0014: 실제 게임을 어레인지한 출시 품질 체험판을 만든다

## 상태

채택 — 2026-07-26

## 맥락

장르만 고르고 내부 규칙을 처음부터 발명하자 GDD를 읽어도 한 판이 그려지지 않는
게임이 나왔다. 반대로 전체 게임의 콘텐츠 양을 요구하면 제작 범위만 커지고 각
시스템의 완성도는 얇아진다.

## 결정

- 선택된 장르에서 실제 출시 게임 하나를 기준작으로 고른다.
- 기준작의 핵심 루프는 알아볼 수 있게 유지한다.
- 변경은 세계, 입력, 진행, 규칙, 매체 중 2~3개 축으로 제한한다.
- 전체 게임 대신 출시 품질의 체험판을 만든다.
- GDD는 기준작, 유지, 변경, 기능 범위표와 체험판 종료를 먼저 적는다.
- `FULL`과 `ADAPTED` 시스템은 완성하고 `OUT` 시스템은 화면에서 약속하지 않는다.
- 모든 게임은 `인트로 → 타이틀 → 게임 → 게임 결과`를 순서대로 제공하며,
  결과에서 다시 시작할 수 있어야 한다.

## 결과

콘텐츠 양은 한 챕터·코스·지역·사건·런으로 제한할 수 있다. 그러나 그 범위 안의
조작, 시스템, 아트, 사운드, 피드백, 절정과 결과는 출시 상태여야 한다. ADR
0009의 “프로토타입이 아닌 품질”은 유지하되 “게임 전체 완성” 목표는 체험판
버티컬 슬라이스로 대체한다.
