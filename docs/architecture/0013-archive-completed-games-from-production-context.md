# ADR 0013: 완료 게임을 이후 제작 맥락에서 아카이빙한다

## 상태

채택 — 2026-07-26

## 맥락

과거 게임의 중립 지문과 플레이 학습만 전달해도 제작자는 이전 해법을 회피하거나
변형하는 방향으로 사고한다. 작품이 늘수록 새 제작 맥락이 과거 기록에 종속된다.

## 결정

- 연번 1–27의 게임 저장소와 제작 기록을 아카이브로 분류한다.
- 공개, 감사, 유지보수와 장애 복구를 위해 원본은 보존한다.
- 새 게임 제작자는 과거 게임의 저장소, GDD, DAY, WHY, ART, 소스, 테스트,
  화면, 공개 기록, 플레이 피드백과 반복 지문을 읽지 않는다.
- ADR 0003의 반복 지문 전달과 ADR 0004의 다음 제작용 PLAYER_FEEDBACK 전달,
  ADR 0011의 최근 10편 구조 비교를 폐기한다.
- 관제만 연번·slug·주 장르의 최소 원장을 사용해 이미 쓴 장르를 피하고,
  제작자에게는 선택된 장르 하나만 전달한다.

## 결과

과거 게임은 기록으로 남지만 새 게임의 설계 재료가 되지 않는다. 장르 다양성은
게임 내용 비교가 아니라 최소 장르 원장으로만 관리한다.
