# 0004 · 지구 플레이어 피드백 루프

## 결정

공개된 게임은 제작자와 분리된 새 맥락의 평가 에이전트가 플레이 증거, 규칙과 화면을 함께 검토한다. 공개 기록에서는 이 평가자를 지구의 고양이 `무르(Murr)`로 표현한다. 무르는 제작자가 아니며 게임에 점수나 등급을 매기지 않는다.

각 평가는 한 줄 인상, 잘 작동한 점, 걸린 점, 깊이 평가, 다음 게임에 넘길 중립적 학습으로 제한한다. 평가는 플레이어의 언어로 쓴다: 화면에서 보이고 손으로 느껴진 것만. 시뮬레이션 정책·검증 수치·내부 상태·검증 방법론은 제작 검증 기록이지 플레이 평가가 아니므로 평가문에 쓰지 않는다. 콘셉트가 노린 재미와 감각이 실제로 느껴졌는지를 답한다. 깊이 평가는 한 판 안에서 숙련 차이가 드러났는지와 한 판이 끝난 뒤 재도전 이유가 생겼는지를 답한다. 확인하지 못한 플레이 경로는 확인한 것처럼 쓰지 않고 근거 범위를 남긴다.

평가 원문은 각 게임의 공개 카탈로그에 한·영으로 기록해 작품 노트에 표시한다. 다음 제작 에이전트에는 제목, 세계, 라이카 서사와 과거 작품 노트를 넘기지 않고 `docs/knowledge/PLAYER_FEEDBACK.md`의 중립 학습만 전달한다.

## 이유

자동 완주와 제작자 회고만으로는 사람이 규칙을 어떻게 읽는지 확인하기 어렵다. 반대로 과거 게임의 공개 서사를 새 제작 입력으로 쓰면 브랜드 블라인드 경계가 무너진다. 관찰과 서사를 분리하면 사람 관점의 실패를 다음 게임에 반영하면서도 새 게임의 창작 독립성을 지킬 수 있다.

## 운영 규칙

- 평가자는 이전 대화를 받지 않는 별도 에이전트로 실행한다.
- 가능하면 직접 플레이하고, 불가능하면 저장된 캡처·스모크·규칙 구현을 교차 검토해 한계를 적는다.
- 기존 공개 게임은 평가 때문에 수정하지 않는다. 별도 수정 요청이 있을 때만 게임 저장소를 연다.
- 중립 학습에는 깊이·재도전에 관한 관찰(숙련 차이, 재도전 이유)을 최소 한 개 포함한다.
- 다음 게임은 최근 피드백에서 검증 가능한 학습을 최대 두 개 선택해 `DAY.md`에 반영 여부와 검증 방법을 남긴다.
- 새 게임 공개 뒤 같은 절차로 평가하고, 중립 학습 문서를 교체한다.
