# ADR 0015: 게임성을 잠근 뒤 고전 아트톤을 적용한다

## 상태

채택 — 2026-07-26

## 맥락

고정된 아트 스타일은 작품군의 시각적 정체성을 만들지만, 제작 초기에 전달하면
규칙까지 짧은 아케이드 액션이나 플랫폼 구조로 수렴시킬 수 있다.

## 결정

- 기준 게임의 핵심 루프, 변경 축, 기능 범위와 체험판 흐름을 먼저 잠근다.
- 그 뒤 별도 아트 패스에서 고전 스타일을 적용한다.
- 2D와 2D 레이어는 16비트 SNES 계열 도트 아트로 만든다.
- 3D와 3D 레이어는 PSX 계열 로우폴리, 저해상도 픽셀 텍스처와 낮은 내부
  해상도 렌더로 만든다.
- 고전 아트톤은 기준 게임에서 바꾸는 2~3개 축에 포함하지 않는다.
- ART.md가 해상도, 팔레트, 보간 또는 모델·텍스처 밀도를 기록하고 체르파가
  실제 플레이에서 확인한다.

## 결과

게임성은 실제 기준 게임과 기능 범위에서 나오고, 아트톤은 그 뒤의 표현
레이어로 남는다. 2D 고해상도 회화·매끈한 벡터 스타일과 3D 현대적 PBR·
포토리얼 스타일은 출시 후보가 아니다.
