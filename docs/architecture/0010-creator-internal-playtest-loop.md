# ADR 0010: 첫 구현을 내부 플레이 뒤 다시 만든다

- 상태: 채택
- 날짜: 2026-07-26
- 적용: sequence 25부터

## 결정

첫 구현은 릴리스 후보가 아니다. 기능 구현 뒤 제작 문서·코드·테스트를 모르는
새 플레이어에게 실제 빌드만 전달한다. 플레이어는 화면에서 이해한 목표, 시도한
입력, 도달한 상태와 걸린 곳을 관찰로 돌려준다.

제작자는 관찰을 바탕으로 게임을 다시 만든다. 무엇을 바꾸고 언제 릴리스
후보라고 판단할지는 제작자의 결정이다. 체르파 검토는 이 내부 플레이와 재제작이
끝난 뒤에만 시작한다.

잠금 게이트는 다음 사실만 확인한다.

- 플레이어가 빌드만 받은 새 맥락이었다.
- 첫 구현과 최종 릴리스 후보의 sourceHash가 다르다.
- 제작자가 관찰과 그에 대응한 변경을 기록했다.
- 기록의 최종 해시가 잠글 빌드와 같다.

플레이어는 합격·불합격을 판정하지 않는다. 완주율, 세션 수, 점수와 받아들여야 할
피드백을 공통 기준으로 만들지 않는다.

## 이유

“풀 프로덕션급”이라는 지시만으로는 기능이 많은 프로토타입이 만들어졌다.
제작자가 첫 구현을 직접 평가하면 구현 의도와 화면 경험을 분리해 보기 어렵다.
창작 자유를 줄이지 않고 첫 구현 직후 출고되는 경로를 끊는다.
