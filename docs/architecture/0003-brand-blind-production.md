# ADR 0003: 브랜드 블라인드 게임 제작

- 상태: 채택
- 날짜: 2026-07-16
- 대체 범위: 게임 선택과 제작에서 라이카가 처음부터 참여하던 절차

## 결정

하루의 게임은 내부 제작과 공개용 라이카 제작 서사를 서로 다른 맥락에서 진행한다.

제작 에이전트는 플랫폼 제약, 품질 기준, 최근 게임의 반복 지문만 받는다. 라이카의 서사와 그림, Sputnik Workshop의 공개 문구, 과거 `WHY.md`, 아케이드 작품 노트는 보지 않는다. 제목, 질문, 규칙, 세계, 시각 매체, 대표 장면을 잠근 뒤 게임 코드·아트·사운드와 플레이 검증을 마친다.

라이카 제작 서사는 제작 잠금 뒤 시작한다. 이때 라이카의 목소리와 그림 기준을 읽고, 라이카가 게임을 직접 만든 것으로 `WHY.md`, 제작자 일러스트, 아케이드 소개와 크레딧을 작성한다. 설명은 잠긴 제작 기록에 근거하며 제목, 규칙, 세계, 팔레트, 게임 아트와 사운드를 바꿀 수 없다.

```text
중립 제약과 반복 지문
        │
        ▼
독립 제작 맥락 ──> 콘셉트 잠금 ──> 게임 제작·플레이 검증 ──> 제작 잠금
                                                               │
                                                               ▼
                                           라이카 제작 서사·공개·운영 검증
```

## 격리

- 콘셉트와 제작은 이전 대화를 물려받지 않는 새 에이전트 맥락에서 수행한다.
- 제작 프롬프트에는 브랜드 이름, 캐릭터, 우주 서사, 과거 공개 카피와 제작자 일러스트를 넣지 않는다.
- 최근 게임은 조작, 재료, 시각 매체, 대표 색, 세션 구조의 반복 지문만 전달한다.
- 제작 저장소의 `AGENTS.md`, `DAY.md`, `ART.md`, `.studio.json`은 라이카 제작 서사 전까지 중립 상태를 유지한다.
- 라이카 제작 서사를 준비할 때 제작 소유 파일과 manifest의 게임 필드를 해시로 잠그고 기준 커밋을 남긴다. 잠금 파일은 읽기 전용이며, `ART.md`와 `DAY.md`는 기존 내용을 보존한 채 부록만 추가할 수 있다.

## 아이디어와 시각 기준

후보는 같은 장르의 표면 변형이 아니라 서로 다른 조작과 시스템 반응으로 벌린다. 핵심 입력 하나를 우선하되, 진행 중 긴장이나 목표가 변해 숙련 판단이 생겨야 한다.

각 후보는 시각 매체와 대표 장면을 함께 제안한다. 래스터 이미지는 의무가 아니며 벡터, 절차 그래픽, 3D, 촬영·생성 이미지 중 게임에 맞는 매체를 고른다. 절차 그래픽만 선택할 때도 대표 장면이 썸네일에서 식별되는지 확인한다.

## 결과

- 라이카의 캡슐, 원형 창, 지구, 팔레트는 공개용 제작자 일러스트에만 적용한다.
- `WHY.md`는 라이카가 제작자로서 주제, 선택과 감산 이유를 설명한다.
- 게임 디자인 판단과 판정 수치는 `DAY.md`, `GDD.md`, 테스트가 소유한다.
- 공개 세계관과 크레딧은 유지하되, 게임 세계를 브랜드 설정으로 통일하지 않는다.
