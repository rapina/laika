# ADR 0009: 프로토타입이 아니라 완성작을 만든다

- 상태: 채택
- 날짜: 2026-07-26
- 적용: sequence 24부터

## 결정

제작자에게 다음 목표를 전달한다.

> 세로형 모바일 디바이스에서 플레이할 수 있는 풀 프로덕션급 웹 게임을 만든다.
> 프로토타입, 기술 데모, 게임잼 출품작처럼 축약하지 않는다. 출시할 완성작이라고
> 판단할 때까지 필요한 시간과 자원을 사용한다.

무엇을 만들고 어떤 기술·규모·테스트를 사용할지는 제작자가 결정한다. 스테이지
수, 플레이 시간, 기능, 콘텐츠 양과 폴리시 항목을 공통 체크리스트로 만들지 않는다.

체르파의 역할도 넓히지 않는다. 제작자가 완성작으로 설계한 문서와 실제 빌드가
일치하는지만 확인한다. 완성도의 취향 평가는 공개 뒤 무르의 기록으로 남긴다.

## 이유

창작 제약과 공통 테스트를 줄였어도 제작 맥락은 일일 제작을 작은 실험으로
해석했다. 자유의 범위를 줄이지 않고 제작 종료 시점만 뒤로 옮긴다.

“풀 프로덕션급”을 기능 수로 번역하면 다시 비슷한 게임과 체크리스트가 생긴다.
따라서 구체적인 범위와 완성 판단은 제작자에게 남긴다.
