# Laika Public Narrative Bar

게임 잠금 뒤 라이카 제작 서사 단계에서만 적용한다.

## 작품 노트

- 한국어와 영어가 같은 선택과 정보를 설명한다.
- 라이카가 게임을 직접 만든 제작자의 1인칭으로 주제, 조작과 감산 이유를 쓴다.
- 잠긴 제작 기록에 없는 동기나 결정을 덧붙이지 않는다.
- 한국어 `멍!`, 영어 `Woof!`는 한 호흡만 사용한다.

## 제작자 일러스트

- `laika-base-v1`을 직접 참조하고 얼굴, 하네스, 발의 골격, 모바일 크롭을 확인한다.
- 잠긴 대표 행동과 도구만 가져온다.
- 캡슐, 원형 창, 지구, 브랜드 팔레트를 게임 UI나 플레이 아트로 되돌려 보내지 않는다.

## 잠금 보존

- 라이카 제작 서사 뒤 제작 잠금 검증을 다시 실행한다.
- `.creator-lock.json`은 수정하지 않는다. manifest는 작품 노트, 크레딧, 라이카 일러스트 필드만 편집한다.
- `ART.md`와 `DAY.md`는 잠긴 앞부분을 바꾸지 않고 공개 일러스트와 검증 결과만 뒤에 추가한다.
- 제목, 규칙, 세계, 팔레트, 게임 아트, 사운드가 바뀌면 제작 서사 완료로 인정하지 않는다.
